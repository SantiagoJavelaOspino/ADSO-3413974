# Sistema de Asistencia de Ambiente — SENA

Aplicación web para registrar, validar y consultar la asistencia de aprendices SENA en ambiente de formación mediante QR rotativo temporal (HMAC), reglas de puntualidad, radicación/gestión de excusas con evidencias y control de acceso por roles (RBAC) bajo una arquitectura de 7 capas.
